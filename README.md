# Кузьмич

Веб-сервис лингвистической поддержки письма на базе локальных больших языковых моделей (LLM). Позволяет редактировать, переводить, перефразировать и анализировать текст с гибкой настройкой системных промптов, встроенной оценкой качества и семантическим поиском.

---

## Ключевые возможности
- 🎛 **Гибкие промпты**: тумблеры, мультиселект и ручное редактирование системных инструкций
-  **Мульти-модельность**: поддержка любых моделей, загруженных в LM Studio
- ⚡ **Потоковая генерация**: мгновенное отображение текста по мере создания
-  **Авто-оценка качества**: грамматика, связность, понятность, увлекательность (шкала 1–100)
- 🔍 **Семантический поиск**: визуализация релевантности фрагментов через тепловую карту
- 📜 **История запросов**: автоматическое сохранение сессий в history.json

---

## Требования
- Python 3.10+
- Windows 10/11 (для .bat скриптов)
- LM Studio (установлен и запущен)
- 8+ ГБ ОЗУ (рекомендуется GPU для быстрых моделей)

---

##  Установка и запуск

### 1. Установка зависимостей
Зависимости можно установить двумя способами:
```bash
# Вариант А: Через готовый скрипт (рекомендуется)
install_requirements.bat

# Вариант Б: Вручную через pip
pip install -r requirements.txt
```

### 2. Настройка LM Studio
1. Скачайте и установите [LM Studio](https://lmstudio.ai/)
2. Загрузите нужные модели (например, Qwen 3 30B, GPT-OSS 20B)
3. Перейдите во вкладку **Server** (иконка ↔️)
4. Включите переключатель **Start Server**
5. Убедитесь, что сервер работает на порту 1234 (по умолчанию)

### 3. Конфигурация приложения
Отредактируйте файл config.yaml в корне проекта:
```yaml
lm_studio:
  host: "127.0.0.1"   # Адрес сервера LM Studio
  port: 1234          # Порт сервера
  api_key: "lm-studio" # Ключ (можно оставить по умолчанию)

app:
  default_model: "openai/gpt-oss-20b" # Модель по умолчанию
  history_file_name: "history.json"
  history_length: 100
```
⚠️ **Важно:** Значение default_model должно точно совпадать с id модели, отображаемым в LM Studio.

### 4. Запуск сервиса
```bash
# Вариант А: Через скрипт
streamlit.bat

# Вариант Б: Вручную
streamlit run app.py
```
Приложение откроется в браузере по адресу `http://localhost:8501`
